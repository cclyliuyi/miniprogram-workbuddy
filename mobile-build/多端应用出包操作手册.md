# 多端应用出包操作手册（照片日历 → Android / iOS）

> 目标：复用现有微信小程序代码，零改后端，直接在微信开发者工具出 Android + iOS 包。
> 适用：已切「多端应用」但 Android 工具包下载失败的情况。

---

## 一、现状确诊（已确认）

- 项目已切「多端应用」，生成了 `app.miniapp.json` / `project.miniapp.json`。
- **下载失败的确凿证据**：`miniprogram/miniapp/android/` 目录为**空（0 字节）**。开发者工具本应把 Android 运行时 + 构建工具（`toolkitVersion 0.11.0` / `sdkVersion 1.7.0`，见 `app.miniapp.json`）下载到 `miniapp/android/nativeResources`，但没下来。
- **次要缺口**：`app.miniapp.json` 里 `mini-android.icons` 与 `mini-android.splashscreen` 目前全是空字符串，构建前必须补真实图片。

## 二、为什么下载会失败

切「多端应用」时，DevTools 需从**微信 CDN** 拉取对应平台工具包。以下任一情况都会留空目录：

1. 网络 / 代理 / 防火墙拦截微信 CDN（公司网络最常见）；
2. 切换中途被打断（关窗口、断网）；
3. 初始化向导里**没勾选 Android** 目标平台（空 `android` 目录即此迹象）。

## 三、修复步骤（在你的机器上的微信开发者工具中）

1. 打开项目，确认顶部出现「多端应用」入口；若没有，先点工具栏「切换到多端应用」。
2. 在「多端应用」面板点 **「下载 / 更新多端工具」**；若无效，**删掉 `miniprogram/miniapp/` 整个目录**，重新「切换到多端应用」让它重新拉取。
3. 确保网络能访问微信 CDN（必要时关代理 / 换网络 / 加白名单 `*.servicewechat.com`）。
4. 重新初始化向导时 **勾选 Android**（要 iOS 也一并勾）。
5. 下载完成后，**补齐图标与闪屏**（见第四节）。
6. 点「编译」→「真机调试」先验证 Android 能跑；再「上传」→ 在 **多端应用管理后台（miniapp.weixin.qq.com）** 下载 APK / IPA。

## 四、必须补齐的配置（`app.miniapp.json`）

当前 `mini-android.icons` / `splashscreen` 为空，需放入对应分辨率 PNG，并在 `app.miniapp.json` 填相对路径（相对于 `miniapp/android/nativeResources/`）：

| 类型 | 分辨率 | 字段 |
|---|---|---|
| 图标 | hdpi 72 / xhdpi 96 / xxhdpi 144 / xxxhdpi 192 | `icons.hdpi / .xhdpi / .xxhdpi / .xxxhdpi` |
| 闪屏 | hdpi / xhdpi / xxhdpi | `splashscreen.hdpi / .xhdpi / .xxhdpi` |

> 快速出图：拿一张 512×512 圆角图，用 Android Asset Studio（在线）一键导出各分辨率，拷到 `miniapp/android/nativeResources/` 对应目录。

## 五、关于 AppID（重要）

- `project.config.json` 的 AppID `wxd9967fc9c09f3b40` 是**普通小程序** AppID。
- 「多端应用」**正式发布**需要 **多端应用专用 AppID**，在 https://miniapp.weixin.qq.com 注册（复用同一微信账号）。
- 当前 `app.miniapp.json` 用「复用小程序」模式（`adapteByMiniprogram.userName: gh_ef67f60e857f`），**开发/预览期可直接跑**；正式分发仍需多端 AppID + 应用签名。

## 六、后端：无需改动（关键利好）

多端应用把小程序运行时塞进原生壳，`wx.cloud` / 云函数 `getPhotos` / 云数据库 `calendar_photos` / 云存储 **照常可用**，直接命中现有云环境 `cloud1-...`。所以这一步**后端零改动**。

## 七、验证清单

- [ ] `miniapp/android/` 下载后有内容（nativeResources + toolkit）
- [ ] 图标 / 闪屏已补齐且路径正确
- [ ] DevTools 内能编译并真机预览 Android
- [ ] 月历网格、翻卡、年视图在安卓真机正常（重点测中低端机）
- [ ] 云图能正常加载（确认云环境 env 仍是 `cloud1-...`）
- [ ] 后台（miniapp.weixin.qq.com）能下载到 APK

## 八、已知限制（决定是否走到 Flutter 独立版）

- 包体含微信运行时，体积偏大；
- 分发走微信多端渠道，**不能当普通 Google Play / App Store App**；
- 依赖微信云环境存活；
- 个别微信专有 API 在多端运行时行为可能微调。

> 如需真正独立、可上架的双端 App，见 `flutter-calendar/README.md`（Flutter 方案，后端换成静态 `manifest.json` + CDN，详见 `backend/`）。
