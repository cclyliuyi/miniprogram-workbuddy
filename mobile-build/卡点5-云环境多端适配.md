# 卡点 #5 预检报告：云环境在多端可见性

> 结论先行：之前「代码层无硬不兼容、云环境随身份通常可直接用」的判断**过早**。查微信官方《多端应用使用云开发》后确认：多端应用里云开发**默认关闭**，且现有 `wx.cloud.init` 写法、匿名访问方式都**不达标**。不处理，多端包能编译过，但**首屏云图必定拉不出来**。

官方文档：https://developers.weixin.qq.com/miniprogram/dev/platform-capabilities/miniapp/new-capability/cloud/cloud.html

## 三道坎（按严重度）

### ① `wx.cloud.init` 缺 `appid` + `envid` —— 代码，已帮你改 ✅
- 官方：多端应用因客户端独立，SDK 不知道 appid/envid，**必须显式传**。
- 原 `app.js`：`wx.cloud.init({ env: 'cloud1-...' })` —— 多端不认。
- 已改为（兼顾小程序与多端）：
  ```js
  wx.cloud.init({
    appid: 'wxd9967fc9c09f3b40', // 云环境所属小程序 AppID（不是多端 AppID）
    env: this.globalData.env,    // 小程序运行时
    envid: this.globalData.env,  // 多端运行时
    traceUser: true,
  });
  ```

### ② 未登录模式必须开启 + 安全规则 —— 云控制台，需你操作 ⬜
你的 app 全程**不调用 `wx.login`**，以匿名方式读云函数/数据库。多端默认**禁止匿名云访问**，必须：
1. 微信开发者工具 → 云开发 → 设置 → 权限设置 → **「未登录用户访问云资源权限设置」打开**（针对 `cloud1-d3gsxamaw26beccb8`）。
2. 云函数安全规则：允许 `getPhotos` 匿名调用 → 粘贴 `cloud-rules/cloudfunction-rule.json`。
3. 数据库安全规则：允许匿名读 → 粘贴 `cloud-rules/database-rule.json`。

> 不放行的话，多端里 `wx.cloud.callFunction('getPhotos')` 直接被安全规则拒掉，首屏空。

### ③ `cloud://` 在 `<image>` 的解析 —— 真机验证点 ⚠️
- `upload.js` 存进数据库的是 **`cloud://` fileID**（非 https）。小程序靠 `<image src="cloud://">` 原生解析。
- **多端运行时是否解析 `cloud://` 需真机确认**。
- 验证：多端 Android 真机跑起来后，看月历缩略图是否显示。
- 若不显示：在 `utils/db.js` 拿到数据后，用 `wx.cloud.getTempFileURL` 批量转成 https 再给 `<image>`（可帮你加这一段）。

## 发布前（用独立多端 AppID 时）
若正式发布注册了独立**多端 AppID**（非复用小程序），需：云开发控制台 → 环境共享 → 添加共享给「移动应用 APPID」；代码改用实例模式 `new wx.cloud.Cloud({ appid, resourceAppid, resourceEnv })`。开发期用「复用小程序」(gh_ef67f60e857f) + 上述①②即可。
