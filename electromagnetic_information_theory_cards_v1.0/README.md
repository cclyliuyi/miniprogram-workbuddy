# 电磁信息论知识卡片资源包 v1.0

本包用于《天线与电波传播》微信小程序“前沿模块——电磁信息论”。

## 目录

- `01_content/`：12张卡片的标准文字、叠加文案CSV。
- `02_images/final_candidates/`：当前独立高清候选图。
- `02_images/reference_crops_01-12/`：由原始12卡合图等比例裁切并放大的参考图。
- `02_images/source/`：原始12卡合图。
- `03_prompts/`：统一视觉规范及12张卡片的图像生成提示词。
- `04_data/`：供小程序或Codex读取的JSON数据和图片映射。
- `05_implementation/`：微信小程序接入建议与上线QA清单。

## 最重要的实现原则

**图片负责解释物理直觉，文字与公式由结构化数据和前端负责。**

不要直接把生成图中的文字当作最终知识内容。请以
`01_content/12_cards_canonical_copy.md`
和
`04_data/cards.json`
为准。
