## 01｜天线收到的到底是什么？

**副标题：** 从电磁场到电信号，再到信息

**核心问题：** 天线接收的是“电”，还是空间中的电磁场？

**课程桥梁：** 坡印廷矢量、功率密度、有效口径

**前沿升级：** 天线是连续电磁场与离散端口信号之间的场—路接口。

**关键公式：** `S = E × H；Pr = ∬A S·n dA`

**一句话结论：** 天线是电磁世界与电路世界之间的桥梁。

**常见误区：** 天线并不是直接“接收电”，而是对入射电磁场进行投影、耦合与转换。

**标签：** 电磁场 / 有效口径 / 能量流 / 信息入口

## 02｜面积越大，信息一定越多吗？

**副标题：** 同样的功率，不同的模式分布，信息量可能不同

**核心问题：** 两套系统总接收功率相同，容量是否必然相同？

**课程桥梁：** 有效口径、天线增益、接收功率

**前沿升级：** 信息量不仅由总功率决定，还由独立电磁模式及各模态信噪比共同决定。

**关键公式：** `Ae = λ²G/(4π)；I = Σn log2(1+γn)`

**一句话结论：** 物理面积决定能收集多少能量；独立模式及其信噪比决定能承载多少信息。

**常见误区：** 大口径通常有利，但“口径更大”不等于容量按面积线性增加。

**标签：** 有效口径 / 模态信噪比 / 互信息 / 空间模式

## 03｜从 Friis 到 Shannon：从功率到容量

**副标题：** 电磁链路决定能量如何到达，信息论决定能量如何被利用

**核心问题：** 同样的接收功率，为什么不同信道结构会产生不同容量？

**课程桥梁：** Friis传输公式、链路预算、信噪比

**前沿升级：** 信道的奇异值把无线链路分解成若干并行本征信道，容量取决于其增益分布。

**关键公式：** `Pr = PtGtGr(λ/4πR)²；C = Σi log2(1+Piσi²/N0)`

**一句话结论：** Friis回答能量如何到达，Shannon回答信息能够通过多少。

**常见误区：** 容量不是接收功率的简单改写，还取决于信道秩、相关性、噪声与功率分配。

**标签：** Friis / Shannon / 奇异值 / 信道容量

## 04｜天线是模式转换器，而非功率收集器

**副标题：** 把连续电磁场投影到一组可观测模式

**核心问题：** 天线如何从无限维连续场中提取有限维信号？

**课程桥梁：** 方向图、极化、互易性、端口

**前沿升级：** 天线通过模式匹配和内积投影，将空间场映射为若干端口系数。

**关键公式：** `vn = ∫S E(r)·En*(r) dr`

**一句话结论：** 天线选择并激励电磁模式，每个有效模式都可能对应一个独立信息通道。

**常见误区：** 天线并非无差别收集全部场能量，而是对特定方向、极化和空间模式具有选择性。

**标签：** 模式转换 / 正交模式 / 场投影 / 信息通道

## 05｜从信道矩阵 H 到电磁算子

**副标题：** 信道不是黑盒，而是由发射、传播与接收共同形成

**核心问题：** 矩阵 H 背后包含哪些真实的电磁过程？

**课程桥梁：** MIMO信道矩阵、多径传播、收发天线

**前沿升级：** 把信道拆解为发射算子、传播算子和接收算子的复合。

**关键公式：** `y = Hx+n；H = RGT；y = RGT x+n`

**一句话结论：** 打开 H，可以看到电流、场、散射、边界、互易与耦合等物理本质。

**常见误区：** H不是脱离物理世界独立存在的随机矩阵，其统计结构由几何、材料、边界和天线共同决定。

**标签：** 信道矩阵 / 电磁算子 / 格林函数 / 多径

## 06｜三种自由度：阵元、信道、场

**副标题：** 三者相关，但绝不等价

**核心问题：** 阵元数、信道秩和电磁场模式数为什么不能混为一谈？

**课程桥梁：** 阵列规模、信道矩阵秩、空间模式

**前沿升级：** 阵元自由度是工程实现维数，信道自由度是可区分本征通道数，场自由度是物理可支持模式数。

**关键公式：** `r = rank(H)，且通常 r ≤ N；场自由度由口径、波长、距离和环境决定`

**一句话结论：** 阵元是手段，信道是桥梁，场是本质。

**常见误区：** 128个阵元最多提供128维端口观测，但不意味着一定存在128个有效独立模式。

**标签：** 阵元自由度 / 信道自由度 / 场自由度 / 物理极限

## 07｜增加阵元 ≠ 增加自由度

**副标题：** 固定口径下，端口加密最终会进入过采样与收益饱和

**核心问题：** 在相同物理口径内，从8个阵元增加到128个阵元，容量会一直线性增加吗？

**课程桥梁：** 阵元间距、阵列采样、互耦

**前沿升级：** 阵元数首先提升场采样能力；当主要场模式已被捕获后，额外端口主要形成冗余观测。

**关键公式：** `N ↑ 不必然导致 rank(H) ↑；有效秩随口径与环境趋于饱和`

**一句话结论：** 端口增加能够改善采样，但不能凭空创造新的电磁模式。

**常见误区：** 天线数量翻倍不代表自由度或容量必然翻倍。

**标签：** 密集阵列 / 过采样 / 有效秩 / 互耦

## 08｜空间采样：天线阵列采样什么？

**副标题：** 阵列采样的是空间带限电磁场，而不是孤立的几何点

**核心问题：** 半波长间距背后的采样对象究竟是什么？

**课程桥梁：** 阵元间距、栅瓣、Nyquist采样

**前沿升级：** 连续电磁场在有限空间频谱和给定精度下可由有限样本表征，但采样不会创造自由度。

**关键公式：** `典型远场无混叠条件：Δx ≤ λ/2（需结合场景与假设理解）`

**一句话结论：** 采样密度取决于空间场包含的细节，而空间细节不等于独立信息自由度。

**常见误区：** λ/2不是所有近场、宽带、非均匀阵列问题中的普适唯一准则。

**标签：** 空间采样 / 空间频谱 / 场重建 / Nyquist

## 09｜多径不是敌人，而是信息资源

**副标题：** 散射环境能够形成空间多样性和独立传播模式

**核心问题：** 为什么复杂多径有时会提高MIMO容量？

**课程桥梁：** 反射、绕射、散射、衰落

**前沿升级：** 不同传播路径在适当的角度、时延、极化和空间结构下，可形成可区分的信息通道。

**关键公式：** `H = Σℓ αℓ ar(Ωr,ℓ) atH(Ωt,ℓ)`

**一句话结论：** 不能被区分的多径是干扰，能够被分离的多径则可能成为自由度。

**常见误区：** 多径并非越多越好；高度相关、损耗过大或不可分辨的路径不会带来有效容量。

**标签：** 多径 / 散射 / 空间多样性 / MIMO

## 10｜从远场角度自由度到近场距离自由度

**副标题：** 远场看方向，近场还可以看距离

**核心问题：** 球面波前为何能区分同一方向、不同距离的用户？

**课程桥梁：** Fraunhofer远场、平面波、阵列波束

**前沿升级：** 超大口径和近距离条件下，波前曲率使距离成为可利用的空间维度。

**关键公式：** `远场近似：R ≫ 2D²/λ；近场保留球面距离 Rmn`

**一句话结论：** 同一角度不再意味着同一空间位置，近场为通信增加了距离域分辨能力。

**常见误区：** 近场优势不只是“波束更窄”，本质是传播核和模式结构发生变化。

**标签：** 近场通信 / 球面波 / 距离域 / LDMA

## 11｜全息 MIMO：连续表面作为信息入口

**副标题：** 从离散天线走向连续超口径，逼近物理极限

**核心问题：** 连续或超密集电磁表面如何同时服务多个空间用户？

**课程桥梁：** 大规模MIMO、阵列口径、波束赋形

**前沿升级：** 连续表面通过更精细的电流与场分布控制，采样和激励高维空间模式。

**关键公式：** `E(r) = ∫S G(r,r')J(r')dr'`

**一句话结论：** 全息MIMO利用连续电磁口径，将空间模式映射为面向多用户的并行通道。

**常见误区：** 表面越密并不自动带来无限容量，仍受口径、损耗、互耦、噪声和传播环境限制。

**标签：** 全息MIMO / 连续口径 / 多用户 / 物理极限

**前沿升级：** 电磁信息论把物理场、模式、噪声、端口和信息量统一到同一框架中。

**一句话结论：** 无线通信的本质，是物理世界向信息世界的层层投影、压缩与提取。

**常见误区：** 电磁信息论不是推翻Shannon理论，而是为信道和约束提供更物理一致的建模基础。
