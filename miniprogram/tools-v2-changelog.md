## 三、工具首页重构（数据驱动）

`pages/tools/index` 三件套重写：

| Before | After |
|--------|-------|
| 433 行手写 WXML，26 个 `goXxx` 处理函数 | 数据注册表（3 分区 32 项）+ 单一 `onCard` |
| 单列瀑布 32 卡，找项滚 6~7 屏 | 综合实验室 14 项改**双列小卡**（3D 项带角标），首屏密度 ×2 |
| 无导航 | sticky 分段锚点（专用计算/交互动画/综合实验室），`pageScrollTo` 260ms 平滑滚动 |
| 无复访入口 | **最近使用**：storage 记录（去重、上限 6），首页顶部横滑 chips，可清空 |
| 3D 与 2D 实验视觉无区分 | 8 个真 3D 项带赤陶→暖金渐变「3D」角标 |

校验：32 个 URL 与 app.json 路由 100% 匹配；index.js `node --check` 通过。
