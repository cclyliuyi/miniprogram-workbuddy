# 学习平台改进实施计划

**Goal:** 修复基础可靠性，交付阻抗匹配学习路线和跨内容搜索收藏。
**Architecture:** 沿用原生小程序，在当前已修改工作区增量实施。365 课程日期与真实日历年份分开；共享资源注册表驱动搜索与收藏。
**Tech Stack:** 微信小程序、CommonJS、Canvas、云开发、Node 内置测试。
**Spec:** 本任务上一轮评估及用户“按照你的建议执行”。
