# 申请并获取 AppID 与云环境 ID · 详细教程

> 针对本项目（照片日历小程序，使用微信云开发）。本项目**只用云开发、不建服务器**，所以你只需要两个东西：
> 1. **AppID（小程序 ID）** —— 来自微信公众平台后台
> 2. **云环境 ID** —— 来自微信开发者工具的「云开发」控制台
>
> 二者不是同一个，别混。下面一步步来。

---

## 0. 先分清两个 ID（很重要）

| 名称 | 是什么 | 在哪拿 | 填到哪 |
|---|---|---|---|
| **AppID** | 小程序的身份证，全局唯一 | 微信公众平台 `mp.weixin.qq.com` → 开发设置 | 开发者工具「导入项目」时填 |
| **云环境 ID** | 云开发资源空间的名字（存图/数据库的地方） | 微信开发者工具顶部「云开发」控制台 | `app.js` 的 `globalData.env` |

本项目用 `wx.cloud.database()` / 云存储，**不需要**自己的服务器，也**不需要**配置服务器域名白名单（云开发请求走微信内部通道，已自动放行）。

---

## 1. 注册小程序账号 → 拿到 AppID

### 步骤 1：进入注册页
打开 https://mp.weixin.qq.com → 右上角点「**立即注册**」→ 在账号类型里选「**小程序**」。
> 注意：这个邮箱**不能**已经注册过公众号/小程序/开放平台，一个邮箱只能一个账号。

### 步骤 2：激活邮箱
- 填邮箱、密码、验证码 → 点注册。
- 去邮箱收激活邮件 → 点链接激活。

### 步骤 3：选择主体类型（关键）
| 主体 | 所需材料 | 费用 | 时效 | 能力 |
|---|---|---|---|---|
| **个人**（推荐本项目用） | 身份证 + 手机号 + 人脸核验 | 免费 | 即时通过 | 云开发✅、分享✅、**无微信支付** |
| **企业/组织** | 营业执照 + 对公打款或微信认证（300 元） | 300 元认证费 | 1–3 天 | 含微信支付、更多接口 |

> 照片日历只是展示+分享，用**个人主体**就够了，省事免费。
> 个人主体限制：一个身份证最多注册 5 个小程序；不能用微信支付、不能做需资质的类目（电商/社交等）。图片日历属于「图片/摄影」或「工具」类目，个人可上。

### 步骤 4：填写小程序信息
- 填名称（如「每日一图」）、简称、上传 logo（可后期改）。
- 名称需合规且尽量唯一；个人主体改名有次数限制，先想好。

### 步骤 5：复制 AppID
进入后台 → 左侧「**开发**」→「**开发管理**」→「**开发设置**」→ 找到 **AppID(小程序ID)**，复制保存。
> 这个 18 位字符串形如 `wx` 开头，就是 AppID。

---

## 2. 开通云开发 → 拿到云环境 ID

### 步骤 1：安装开发者工具
下载「**稳定版 Stable Build**」微信开发者工具：
https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
按系统选 Windows 64 或 macOS 版安装。

### 步骤 2：导入项目并填 AppID
- 打开开发者工具 → 「导入项目」或「+ 新建项目」。
- 目录选本项目的 `miniprogram/` 文件夹。
- **AppID** 一栏：填第 1 步拿到的真实 AppID（不要选「测试号」，测试号不能开云开发）。
- 后端服务选「**微信云开发**」。
- 点「导入 / 新建」。

### 步骤 3：开通云开发
- 工具顶部工具栏点「**云开发**」按钮（首次会弹协议）→ 同意 → 开始开通。
- 若提示需**实名**，按引导完成（个人用身份证人脸即可；企业按主体认证）。
- 开通后有**免费配额**（存储/CDN/云函数调用额度，个人项目够用；超额才计费）。

### 步骤 4：创建环境 → 拿环境 ID
- 在云开发控制台点「**新建环境**」（或环境下拉 → 创建）。
- 环境名称：自取，如 `photo-calendar`。
- **环境 ID**：系统自动生成（形如 `photo-calendar-1gabcd123`），创建后**只能改一次**，建议一次想好；记下它。
- 等待环境初始化完成（几十秒到几分钟）。

### 步骤 5：把环境 ID 填进代码
打开 `miniprogram/app.js`，找到：
```js
globalData: {
  env: 'your-cloud-env-id',  // ← 改成你的环境 ID
  ...
}
```
把 `'your-cloud-env-id'` 替换成第 4 步记下的环境 ID。

## 3. 建数据库集合

云开发控制台 → 左侧「**数据库**」→「**新建集合**」→ 集合名填 **`calendar_photos`** → 确定。
> 本项目所有照片映射都写在这个集合里（脚本会自动写入，这里只要建空集合）。

## 5. 常见坑 & 答疑

**Q1：个人号能用云开发吗？**
能。云开发对个人、企业都开放，免费额度一致。

**Q2：一定要备案域名吗？**
本项目**不用**。因为全程只调 `wx.cloud.*`（云数据库/云存储/云函数），这些走微信内部通道，不占 `wx.request` 合法域名白名单。只有你以后自建 HTTP 服务器才需要备案+配白名单。

**Q3：可以用「测试号」(touristappid) 吗？**
开发者工具勾「使用测试号」能预览基础组件，但**云开发必须绑真实 AppID + 已实名的环境**，所以本项目请填真实 AppID。

**Q4：云开发收钱吗？**
有免费配额（存储 5GB、CDN 5GB、云函数调用/容量等），个人照片日历量级（730 张图）基本在免费额度内。超额才按量计费，价格很低。

**Q5：AppID 和环境 ID 搞反了会怎样？**
小程序能编译但云能力报错（如 `errCode: -1` / 环境不存在）。检查：AppID 在公众平台，环境 ID 在开发者工具云控制台；`app.js` 里填的是**环境 ID**，不是 AppID。

**Q6：环境 ID 创建后能改吗？**
能改一次。若改了，记得同步更新 `app.js` 的 `globalData.env`。

**Q7：提审要注意什么？**
准备《隐私保护指引》（后台「设置→服务内容声明/用户隐私」），账号用途如实写「个人照片日历展示」；不要在无场景页申请相册/位置权限（本项目仅在「日签卡」页触发保存相册权限，合规）。

**Q8：新版控制台找不到「微信云开发 Secret」怎么办？**
腾讯经常改版控制台 UI。如果你在「设置」页也找不到 SecretId/SecretKey：
- **首选**：用方式 A（`tcb login` 扫码），完全不需要找 Secret
- **备选**：去 [腾讯云 CAM 控制台](https://console.cloud.tencent.com/cam/capi) 创建 API 密钥，那个 SecretId/SecretKey 也能用于 `@cloudbase/node-sdk`
- **原因**：新版云开发底层已迁移到腾讯云，凭证体系统一到了 CAM（Cloud Access Management）

## 6. 上传图片到云开发（两种认证方式）

> ⚠️ **重要**：本步骤在**你的电脑上**用 Node.js 脚本批量上传 730 张图 + 写数据库。需要在云开发控制台获取凭证。

### 方式 A：Cloudbase CLI 扫码登录（推荐，最简单）

```bash
# 1. 安装 Cloudbase 命令行工具
npm i -g @cloudbase/cli

# 2. 扫码登录（弹出二维码，微信扫一扫）
tcb login

# 3. 登录成功后直接跑上传脚本
cd miniprogram/tools
node upload.js
```

> 扫一次码就行，之后脚本自动读取本地凭证，不用每次再扫码。

### 方式 B：使用 Secret Key（传统方式）

如果你找不到「设置」里的 Secret，或者不想装 CLI，可以用这个方式：

1. 在云开发控制台左侧菜单点 **「设置」**（最底部）
2. 找到 **「基础信息」** 或 **「环境信息」** 区域
3. 复制 **SecretId** 和 **SecretKey**（有些版本叫「环境凭证」或「微信云开发 Secret」）
4. 运行：
```bash
cd miniprogram/tools
TCB_ENV=你的环境ID TCB_SECRET_ID=xxx TCB_SECRET_KEY=xxx node upload.js
```

> **新版控制台提示**：如果你看到的界面和教程描述不完全一致（腾讯经常改版），Secret 一般都在 **「设置」** 页面的 **「基础信息 / 环境信息 / 安全设置」** 其中一个区域里。实在找不到就用方式 A（CLI 扫码）。

### 上传前先跑预处理

无论哪种方式，都要先执行预处理生成缩略图：
```bash
cd miniprogram/tools
npm init -y
npm i sharp @cloudbase/node-sdk @cloudbase/manager-node   # 方式A需额外装 manager-node
node preprocess.js    # 生成 output/ 目录（含缩略图+manifest.json）
# 然后再跑上面的 upload.js
```

### 上传过程说明

- 脚本会读取 `output/manifest.json`（由 preprocess.js 生成）
- 每张图上传三档：thumb(400px) / preview(1080px) / original(原图)
- 全部存入云存储的 `calendar/` 目录下
- 最后按天合并正反面，写入集合 `calendar_photos`
- 预计耗时：取决于网速，一般 5-15 分钟
