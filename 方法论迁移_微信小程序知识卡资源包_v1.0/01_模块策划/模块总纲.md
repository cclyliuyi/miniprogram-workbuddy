# 模块总纲：方法论迁移

## 模块名称
方法论迁移

## 副标题
从电磁系统到智能系统：电子信息人的 AI 时代认知跃迁

## 核心痛点
电子信息类学生已经掌握系统、响应、建模、边界、变换和优化，但面对长程 Agent、自进化 Agent 和多工具协同系统时，常常缺少软件工程与 Agent 工程的表达框架。

问题不一定是能力不足，而是已有能力没有完成抽象和迁移。

## 三套方法论

### 电子信息方法论：理解自然系统
输入输出、系统响应、数学建模、表征变换、边界条件、反馈控制、约束优化、测量验证。

### 软件工程方法论：构造复杂人工系统
抽象、分层、模块化、接口契约、状态管理、生命周期、测试验证、日志监控、版本管理、故障恢复。

### AI Agent 方法论：设计与治理自主智能系统
目标规格、权限边界、工具协议、工作流编排、记忆与状态、评价审计、人机协同、失败恢复、持续学习与受控进化。

## 迁移主链
1. 从“输入—系统—输出”迁移到“目标—Agent—行动—结果”。
2. 从“边界条件决定场”迁移到“权限边界决定行为域”。
3. 从“端口与阻抗匹配”迁移到“接口与协议契约”。
4. 从“仿真—测量—校准”迁移到“测试—评测—审计”。
5. 从“反馈控制与自适应”迁移到“反思—记忆—策略更新”。
6. 从“天线指标优化”迁移到“Agent 多目标治理”。

## 教学目标
完成模块后，学习者应能够：
- 用系统语言描述一个 AI Agent；
- 将目标、边界、约束、工具、状态、评价和输出写成可执行规格；
- 设计可验证、可中断、可回滚的长程 Agent 工作流；
- 识别电子信息方法论与软件工程方法论之间的同构关系；
- 将天线设计能力迁移为智能系统设计能力。
