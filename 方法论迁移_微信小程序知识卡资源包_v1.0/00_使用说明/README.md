# 《方法论迁移》微信小程序知识卡资源包 v1.0

## 1. 资源包定位

本资源包用于《天线与电波传播》微信小程序新增模块“方法论迁移”。

模块主线：

电子信息方法论（理解自然系统）
→ 软件工程方法论（构造复杂人工系统）
→ AI Agent 方法论（设计与治理自主智能系统）

核心观点：

> 天线工程师一直在学习如何在目标与约束下设计结构，使系统产生期望响应。  
> AI Agent 只是把“响应对象”从电磁场扩展到了智能行为。

## 4. 推荐生产方式

DALL·E 或其他生成模型负责：
- 背景、科学插画、结构图、图标和艺术表现。

小程序前端负责：
- 所有长中文正文；
- 标题、公式、关键词和哲思句的最终排版；
- 点击展开、知识点跳转和卡片间关联。

原因：生成模型对密集中文、公式和小字号仍可能出现错字。正式出版级内容应当采用“生成视觉底图 + 前端精确叠字”的混合方式。

## 5. 建议页面字段

每张卡片至少包含：

`id / title / subtitle / stage / core / sections / mappings / keywords / quote / image / image_status`

详细字段见 `05_小程序开发数据/cards_full.json`。
