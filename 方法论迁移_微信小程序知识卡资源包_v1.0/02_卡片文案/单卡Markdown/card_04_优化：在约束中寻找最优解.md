# 04 优化：在约束中寻找最优解

## 副标题
工程的本质是在约束下追求可达的最好

## 所属阶段
电子信息 → 软件工程

## 核心命题
现实工程不存在脱离资源、成本、安全和物理条件的绝对最优。

## 电子信息视角
天线设计同时考虑增益、驻波、效率、带宽、尺寸、材料、加工与成本。

## 软件工程视角
软件系统同时权衡性能、可靠性、开发周期、可维护性和资源消耗。

## AI Agent 视角
Agent 要在质量、时间、Token、工具成本、风险和人工介入之间做多目标权衡。

## 迁移映射
- 设计变量 → Agent策略参数
- 目标函数 → 完成质量
- 约束条件 → 权限/预算/时限
- 测量验证 → 评测与回归测试

## 卡片信息模块
### 天线优化
目标 + 约束 + 设计变量 + 仿真/测量

### 通用形式
min/max F(x)，s.t. g_i(x)≤0，h_j(x)=0

### 工程权衡
性能提升通常伴随成本、尺寸或风险增加

### 优化闭环
建立模型 → 定义目标 → 搜索策略 → 评估验证 → 迭代改进

## 关键词
优化、约束、权衡、多目标、可达性

## 哲思句
> 优化不是找到最好，而是在现实中找到可达的最好。
