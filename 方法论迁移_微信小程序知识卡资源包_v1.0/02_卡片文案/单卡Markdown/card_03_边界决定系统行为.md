# 03 边界决定系统行为

## 副标题
从边界条件到权限边界

## 所属阶段
电子信息 → 软件工程

## 核心命题
相同的基本规律，在不同边界条件下会产生完全不同的行为。

## 电子信息视角
麦克斯韦方程只有与导体、介质、辐射和周期边界等条件共同使用，才能确定唯一电磁响应。

## 软件工程视角
模块边界、数据边界和权限边界决定系统能访问什么、修改什么以及如何协作。

## AI Agent 视角
模型能力只是潜能；权限、工具、数据、时间和审批边界决定 Agent 的真实行为域。

## 迁移映射
- 导体边界 → 禁止访问区
- 介质界面 → 权限切换
- 吸收边界 → 输出过滤
- 周期边界 → 循环执行规则

## 卡片信息模块
### 电磁边界
方程 + 边界条件 + 材料参数 → 电磁场分布

### Agent边界
模型 + 权限边界 + 工具约束 → 智能行为范围

### 边界类型
物理、信息、工具、行为、时间、输出边界

### 工程建议
明确任务目标；最小权限；分层约束；持续监控；迭代优化

## 关键词
边界、权限、条件、安全、可控

## 哲思句
> 自由的前提是边界，智能的基础是约束。
