# 11 提示词不是命令，而是系统设计

## 副标题
从单句指令到可执行任务规格

## 所属阶段
AI Agent方法论

## 核心命题
高质量 Prompt 的本质不是修辞技巧，而是用结构化语言定义一个临时的软件系统和执行契约。

## 电子信息视角
一个电磁问题需要激励、几何、材料、边界、观测量和误差要求，缺一项都可能无法求解。

## 软件工程视角
需求规格需要角色、功能、输入输出、异常、性能和验收标准。

## AI Agent 视角
系统化 Prompt 应包含角色、目标、上下文、约束、工具、流程、评价标准、输出格式和停止条件。

## 迁移映射
- 激励 → 任务目标
- 边界条件 → 权限与禁区
- 材料参数 → 环境与资源
- 观测量 → 输出字段
- 误差限 → 验收标准

## 卡片信息模块
### 命令式 Prompt
只描述一句要做什么，边界与质量标准模糊

### 系统化 Prompt
Role、Goal、Context、Constraints、Tools、Workflow、Criteria、Format

### 长程任务附加项
检查点、状态保存、失败恢复、版本、证据与审计

### Prompt质检
是否可执行、可判断、可验证、可恢复、可复用

## 关键词
Prompt、系统设计、任务规格、验收标准、可执行性

## 哲思句
> 提示词的质量，决定了智能系统能够看见的边界和必须承担的责任。
