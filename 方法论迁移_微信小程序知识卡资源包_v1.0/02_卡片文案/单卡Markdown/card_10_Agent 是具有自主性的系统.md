# 10 Agent 是具有自主性的系统

## 副标题
从被动执行到主动决策

## 所属阶段
AI Agent方法论

## 核心命题
自主性不是无限自由，而是在既定目标、边界和评价机制中选择下一步行动的能力。

## 电子信息视角
闭环控制系统根据状态与误差自主调整控制量，但其稳定性由控制律和边界保证。

## 软件工程视角
传统程序主要执行预定义流程，对未知情形的处理范围有限。

## AI Agent 视角
Agent 具备感知、记忆、推理、规划、工具调用、反馈修正与终止判断。

## 迁移映射
- 传感器 → 观察
- 状态估计 → 工作记忆
- 控制律 → 策略
- 执行器 → 工具
- 闭环反馈 → 反思与重规划

## 卡片信息模块
### Agent闭环
观察 → 理解 → 规划 → 行动 → 反馈

### 自主性的层级
响应式、任务式、规划式、协作式、自我改进式

### 自主性边界
权限、预算、风险、时限、审批、终止条件

### 工程原则
可观测、可中断、可回滚、可解释、可升级

## 关键词
自主性、闭环、决策、工具、治理

## 哲思句
> 自主不是摆脱约束，而是在约束中承担选择的责任。
