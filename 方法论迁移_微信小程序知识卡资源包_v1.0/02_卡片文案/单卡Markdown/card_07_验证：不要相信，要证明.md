# 07 验证：不要相信，要证明

## 副标题
从仿真测量到测试与审计

## 所属阶段
软件工程方法论

## 核心命题
系统输出不能因为“看起来合理”就被接受，必须通过独立证据、边界测试和可追溯记录建立可信度。

## 电子信息视角
理论推导需要仿真验证，仿真结果需要暗室测量，测量还需要校准与误差分析。

## 软件工程视角
单元测试、集成测试、系统测试、性能测试和安全测试共同证明软件可用。

## AI Agent 视角
事实核查、工具结果复验、评价器、日志、引用和人工抽检共同构成可信闭环。

## 迁移映射
- 解析解 → 规格与不变量
- 数值仿真 → 自动化测试
- 暗室测量 → 真实环境评测
- 校准误差 → 偏差与幻觉分析

## 卡片信息模块
### 电磁验证链
理论 → 仿真 → 测量 → 误差分析

### 软件验证链
单元 → 集成 → 系统 → 回归

### Agent验证链
生成 → 事实核验 → 工具复算 → 审计评估

### 可信四问
结果正确吗？证据独立吗？过程可复现吗？失败可定位吗？

## 关键词
验证、测试、证据、审计、可复现

## 哲思句
> 可信不是系统对自己的评价，而是独立证据共同指向的结果。
