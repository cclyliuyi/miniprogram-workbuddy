# 09 从输入输出到目标驱动

## 副标题
从传递函数到任务规划

## 所属阶段
AI Agent方法论

## 核心命题
传统系统接收明确输入并执行预定变换；Agent 接收目标，自主构造中间步骤并选择行动。

## 电子信息视角
确定输入 x 和系统 H 后，输出 y 通常由系统响应关系给出。

## 软件工程视角
传统程序由开发者提前规定分支、顺序与异常处理。

## AI Agent 视角
Agent 将目标分解为子任务，检索信息、调用工具、检查结果，并根据反馈重规划。

## 迁移映射
- 输入信号 x → 目标 G
- 传递函数 H → 策略与规划器
- 中间状态 → 子任务与工作记忆
- 输出 y → 可验收成果

## 卡片信息模块
### 输入驱动
输入 → 程序 → 输出

### 目标驱动
目标 → 规划 → 行动 → 观察 → 重规划 → 结果

### 关键变化
人从描述步骤转向定义目标、边界、验收标准与资源

### 目标规格
成果是什么、何时完成、质量多高、证据是什么、哪些行为禁止

## 关键词
目标、规划、行动、重规划、验收

## 哲思句
> AI 时代最重要的能力，不只是告诉机器怎么做，而是准确规定什么叫做成。
