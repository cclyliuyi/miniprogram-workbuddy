# 06 接口：让复杂系统协同工作

## 副标题
从物理接口到 API 与工具协议

## 所属阶段
软件工程方法论

## 核心命题
复杂系统能否协作，取决于接口是否明确、稳定、可验证，而不是各模块是否彼此了解全部细节。

## 电子信息视角
馈电端口定义阻抗、电压电流和功率传输；空间接口定义波的传播与耦合关系。

## 软件工程视角
API 规定输入、输出、错误码、状态和版本，使模块可独立演化。

## AI Agent 视角
工具协议规定 Agent 何时调用工具、传入什么参数、如何解析结果及处理失败。

## 迁移映射
- 端口阻抗 → 数据契约
- 功率匹配 → 协议兼容
- 反射损耗 → 接口错误
- 校准去嵌 → 适配与中间层

## 卡片信息模块
### 电磁接口
馈电端口、自由空间、介质界面、测量端口

### 软件接口
函数、API、消息队列、数据库协议

### Agent接口
模型—工具、Agent—Agent、Agent—人、Agent—环境

### 优质接口标准
契约清晰、输入可校验、失败可恢复、版本可演化、过程可观测

## 关键词
接口、协议、契约、协同、解耦

## 哲思句
> 伟大的系统不是因为每个模块无所不能，而是因为它们能够可靠协同。
