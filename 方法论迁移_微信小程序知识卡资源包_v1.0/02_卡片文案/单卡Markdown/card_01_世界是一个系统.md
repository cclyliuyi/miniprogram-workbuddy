# 01 世界是一个系统

## 副标题
从电磁场到系统科学

## 所属阶段
电子信息方法论

## 核心命题
世界不是孤立对象的集合，而是输入、结构、环境与输出之间的关系网络。

## 电子信息视角
激励电流经过天线结构与传播环境，形成空间电磁场并被接收端感知。

## 软件工程视角
任何复杂功能都可以先抽象为输入—处理—输出，再分析内部结构与外部条件。

## AI Agent 视角
Agent 不是一个孤立模型，而是由目标、模型、记忆、工具、环境和反馈构成的系统。

## 迁移映射
- 激励源 → 任务输入
- 天线与信道 → Agent与环境
- 接收响应 → 任务结果
- 系统测量 → 运行反馈

## 卡片信息模块
### 电磁系统示例
激励电流 → 天线结构 → 空间传播 → 接收信号

### 系统思维模型
输入 x(t) → 系统 H → 输出 y(t)，即 y(t)=H{x(t)}

### 现实世界映射
通信、声学、控制、经济、生物系统都可用系统关系理解

### 迁移要点
先界定系统，再识别输入、输出、内部机制与环境耦合

## 关键词
系统、响应、输入输出、传递关系、因果链

## 哲思句
> 工程的起点不是计算，而是看清系统的边界与关系。
